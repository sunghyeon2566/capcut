# 딥마크온 클래스 무료 특강 — 홍보 모션 영상

- 결과물: `out/deepmarkon-free-lecture.mp4` (1920×1080, 30fps, 39초, 소리 포함)
- 내용 출처: 딥마크온 클래스 무료 특강 랜딩페이지(문구·일시·숫자는 랜딩에 있는 것만 사용)
- 스타일: 레퍼런스 영상(크림 바탕 ↔ 검은 바탕, 단색 강조, 단어 리빌, 칩, 폰 목업, 슬롯 판정, 파티클 → 글자, 로고 엔딩)의 구조와 120BPM 리듬을 그대로 옮김

## 구성

| 시간 | 장면 | 화면 |
|---|---|---|
| 0.0–2.0 | open | 검은 화면, 재생 아이콘·썸네일이 터져 나오며 "열심히 만드는데," |
| 2.0–4.5 | hook | "왜 내 영상은 / 안 될까요?" |
| 4.5–9.0 | brand | 파란 점 → 마크, "딥마크온 클래스 / 무료 특강." + 일시 알약 |
| 9.0–14.5 | check | 고민 3가지 칩 → CHECK 박스 → "문제는 노력이 아니라 방법입니다." |
| 14.5–19.5 | method | "누구나 1시간 안에 / 1시간짜리 영상 완성." + 4단계 + 폰 화면 |
| 19.5–22.5 | verdict | 검은 물결, "그래서, 결과는?" 슬롯이 "애드센스 성공"에 멈춤 |
| 22.5–27.5 | result | 폰 화면 확대에서 빠지며 200명(챌린지 1기·2기) → 60명(상장·상금) |
| 27.5–32.0 | take | "이번 특강에서 가져가실 것." 노드 그래프 4가지 |
| 32.0–35.0 | free | 점들이 모여 "100% 무료" |
| 35.0–39.0 | end | 마크 + 딥마크온 클래스 + 10월 30일 (금) 저녁 8시 30분 + 줌 참여 안내 |

## 다시 렌더하기

필요: Node 18+, ffmpeg, Python 3 + numpy, Playwright(Chromium)

```bash
cd video/deepmarkon-free-lecture
bash fetch_fonts.sh fonts "Noto Sans KR:500,700,900" "Noto Serif KR:700" "Montserrat:600,800"   # 폰트는 저장소에 넣지 않음
python3 sound.py                                                                                 # out/sound.wav
node render.mjs . --stills 3,7,12,17,21,25,30,34,37                                              # 스틸 확인
node render.mjs . --audio out/sound.wav --out out/deepmarkon-free-lecture.mp4                    # 전체 렌더(약 1분)
```

미리보기: 이 폴더를 정적 서버로 열고(`npx serve .` 등) `index.html` 에서 재생·탐색.

## 고치는 곳 (`index.html` 맨 위)

- `COPY` — 화면 문구. 날짜(`date`), 고민 3가지(`pains`), 4단계(`steps`), 가져가실 것(`takes`), 참여 안내(`join`) 등
- `T` — 장면 시작·끝 시각. 바꾸면 `sound.py` 의 `T` 도 같은 값으로
- `C` — 색. 강조색 `blue`(#1565e0), 일시 알약 `red`(#e53935), 바탕 `cream`·`black`

## 확인할 것

- 마크(책갈피 + 재생 삼각형)는 직접 그린 것으로 **공식 로고가 아닙니다.** 공식 로고 파일을 주시면 교체할 수 있습니다.
- 사운드는 합성한 가이드 트랙입니다. 편집 툴(캡컷 등)에서 BGM을 바꿔도 컷은 120BPM 박에 맞춰져 있습니다.
