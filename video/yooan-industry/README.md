- 결과물: `out/yooan-industry.mp4` (1080×1080 정사각형, 30fps, 25.3초, 소리 포함)

  아래쪽 진행 점, 흰 섬광 전환, 마지막 점선 원 안의 두 줄 문구)의 구조와 리듬을 그대로 옮김

## 다시 렌더하기

필요: Node 18+, ffmpeg, Python 3 + numpy, Playwright(Chromium)

```bash
cd video/yooan-industry
bash fetch_fonts.sh fonts "Noto Sans KR:500,700,900" "Noto Serif KR:700" "Montserrat:600,800"   # 폰트는 저장소에 넣지 않음
python3 sound.py                                                                                 # out/sound.wav
node render.mjs . --stills 1.6,3.6,5.8,8,10.2,12.4,14.6,16.8,19,21.2,24.5                         # 스틸 확인
node render.mjs . --audio out/sound.wav --out out/yooan-industry.mp4                             # 전체 렌더(약 40초)
```

## 고치는 곳 (`index.html` 맨 위)

- `CHAPTERS` — 장마다 상단 네온 글자(`top`), 색(`color`), 아이콘(`icon`), 제목(`title`), 설명(`sub`). 장을 더하거나 빼면 진행 점과 길이가 따라 바뀐다
- `COPY` — 인트로·원 문구·엔딩(회사명, 인증, 제품, 홈페이지, 주소)
- `CH` — 한 장의 길이(초). 바꾸면 `sound.py` 의 `CH` 도 같이
- `logo()` — 브로슈어 표지 로고를 보고 벡터로 다시 그린 것. 원본 파일이 있으면 이미지로 바꿀 수 있다

## 확인할 것

- 로고는 브로슈어 사진을 보고 다시 그린 것입니다. 원본 로고 파일을 주시면 정확히 교체합니다.
- 브로슈어 기준 정보(연혁은 2002년까지, 주소는 지번 주소)입니다. 이후 연혁·현재 주소·전화번호가 있으면 추가할 수 있습니다.
- 인원·자본금·설비 대수는 시간이 지나 바뀌었을 수 있어 영상에 넣지 않았습니다.
- 브로슈어 사진 속 고객사 상자(타사 상표)는 영상에 쓰지 않았습니다.
- 사운드는 합성한 가이드 트랙입니다(레퍼런스에는 소리가 없었음).
