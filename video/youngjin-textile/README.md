# (주)영진텍스타일 — 홍보 모션 영상

- 결과물: `out/youngjin-textile.mp4` (1920×1080, 30fps, 50초, 합성 음악). 사진 없는 초안은 `out/youngjin-textile-draft.mp4`
- 내용 출처: 회사 정보 정리 이미지(상호·대표·담당·이메일·공장 주소·생산품목·납품실적·인력·최소수량)
- 스타일: 레퍼런스("ONE SECOND" — 검은 우주, 입자로 모이는 제목, 크게 올라가는 숫자 + 기울임 설명, 빛나는 천체, 심전도 선,
  짧은 문장, 입자 폭발 뒤 제목)를 따르고 천체 자리에 실패·테이프 롤·직조 라벨, 심전도 자리에 박음질 선을 둔다

## 사진 넣기

`assets/` 에 아래 이름으로 넣으면 그 장면에서 그래픽 대신 사진을 쓴다(없으면 그래픽).

- `factory1.jpg`, `factory2.jpg` — 공장 내부(직기)
- `products.jpg` — 제품 모음
- `pet.jpg` — 반려동물 하네스·목줄

## 다시 렌더하기

```bash
cd video/youngjin-textile
python3 sound.py                                                         # out/sound.wav
node render.mjs . --stills 2,4.5,11,17,22.5,25.5,30,35.5,38,41,47.5      # 스틸 확인
node render.mjs . --audio out/sound.wav --out out/youngjin-textile.mp4   # 전체 렌더(약 1분)
```

폰트: Noto Sans KR 500/700/900, Noto Serif KR 700, Inter 800, JetBrains Mono 400/700, Instrument Serif Italic(`fetch_fonts.sh`).

## 저장소에 올리지 않은 파일

- 엔딩 연락처 `local.js`(`window.LOCAL = { contact: '...', biz: '...' }`) — 없으면 엔딩에서 연락처 줄이 빠진다
- 결과 영상(`out/`)
