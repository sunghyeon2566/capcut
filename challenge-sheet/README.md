# 유튜브 민담영상 챌린지 자동 현황판

구글 시트 하나로 돌아가는 챌린지 관리 도구입니다.
수강생은 **이름 · 채널명 · 채널 링크**를 한 번만 등록하면 되고, 나머지는 자동입니다.

- 매일 업로드했는지 날짜별로 자동 체크 (● 업로드 / ✕ 누락 / ○ 오늘 아직)
- 이달(1~30일) 업로드한 영상들의 조회수를 자동 합산
- **하루도 빠지지 않은 사람만** 조회수 순으로 순위 · 상금 표시
- 몇 시간마다 자동 갱신, 월말에 결과 보관

> API 키는 필요 없습니다. 시트 주인의 구글 계정으로 YouTube에 접속합니다.

## 처음 설치 (10분, 한 번만)

1. [sheets.new](https://sheets.new) 에서 새 구글 시트를 만들고 이름을 정합니다. (예: `민담영상 챌린지`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 붙여넣은 뒤 저장(💾)합니다.
4. 왼쪽 **서비스 옆 +** → `YouTube Data API v3` 선택 → **추가**
   (식별자는 기본값 `YouTube` 그대로 둡니다)
5. 시트 탭으로 돌아와 새로고침하면 위쪽 메뉴에 **🏆 챌린지** 가 생깁니다.
6. **🏆 챌린지 → ① 처음 설정하기** 클릭
   - 처음 한 번 "권한 승인" 창이 뜹니다 → 내 계정 선택 → *고급* → *(안전하지 않음)으로 이동* → 허용
     (내가 만든 스크립트라 뜨는 경고이며 정상입니다)
7. **② 참가 신청 구글폼 만들기** → 나오는 링크를 수강생 단톡방에 공유
8. **③ 자동 갱신 켜기** → 끝!

## 시트 구성

| 시트 | 역할 | 누가 |
|---|---|---|
| 현황판 | 순위 · 30일 업로드 달력 · 조회수 · 상금 | 자동 |
| 참가자 | 이름 / 채널명 / 채널 링크 (+자동 확인 결과) | 폼으로 자동 입력, 직접 추가도 가능 |
| 영상목록 | 이달 올라온 영상 전체 (날짜 · 제목 · 링크 · 조회수) | 자동 |
| 설정 | 챌린지 월 · 기간 · 갱신 간격 · 등수별 상금 | 관리자 |

## 판정 규칙

- 날짜는 **한국 시간** 기준입니다. (11/1 00:00 ~ 11/30 23:59)
- 하루에 여러 개 올려도 그날은 1일로 칩니다. 조회수는 모두 합산합니다.
- **공개 영상**만 집계됩니다. 비공개 · 예약 · 일부공개 영상은 보이지 않습니다.
- 지난 날 중 하루라도 업로드가 없으면 `탈락`으로 표시되고 순위에서 빠집니다.
- 개근자끼리는 **이달 업로드 영상 조회수 합계**로만 순위를 매깁니다.
- 2월처럼 30일이 없는 달은 그 달의 마지막 날까지로 자동 조정됩니다.

## 매월 운영

- **월초**: 설정의 `챌린지 월` 을 비워두면 자동으로 이번 달이 됩니다.
- **월말(31일 또는 다음 달 1일 아침)**: `🏆 챌린지 → 지금 조회수 갱신` 후
  `이번 달 결과 보관하기` → `결과_2026-11` 같은 시트로 그대로 저장됩니다. 이 표로 상장 · 상금을 지급하세요.
- 다음 달 참가자를 새로 받으려면 참가자 시트에서 지난 달 사람을 지우면 됩니다.
  (계속 하는 사람은 그대로 두면 다음 달에도 자동 집계)

## 수강생에게 보여주기

- 시트 오른쪽 위 **공유 → 링크가 있는 모든 사용자: 뷰어** 로 링크를 주거나
- **파일 → 공유 → 웹에 게시 → `현황판` 시트만** 게시하면 깔끔한 웹페이지로 볼 수 있습니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 참가자 상태가 `채널을 찾을 수 없음` | 링크를 `https://www.youtube.com/@핸들` 형태로 고친 뒤, 같은 줄의 `채널ID (자동)` 칸을 비우고 갱신 |
| 상태가 `검색으로 찾음 - 확인` | 링크만으로 채널을 못 찾아 이름으로 검색한 것. `확인된 채널명` 이 맞는지 보세요. 틀리면 위와 같이 링크 수정 |
| 수강생이 채널을 바꿈 | 참가자 시트의 링크를 고치고 `채널ID (자동)` 칸을 비우기 |
| 메뉴가 안 보임 | 시트를 새로고침 |
| 갱신이 안 됨 | Apps Script 왼쪽 ⏰ 트리거에 `refreshAll` 이 있는지 확인, 없으면 `③ 자동 갱신 켜기` 다시 클릭 |

YouTube 무료 사용량(하루 10,000)으로 참가자 수백 명까지 4시간 간격 갱신이 충분합니다.
