# 품질 체크리스트 — 실제로 겪은 문제와 해법

스틸 검토 때마다 이 목록을 위에서부터 훑는다. 각 항목은 실제 제작 중 사용자에게 보이기 전에
잡았어야 했던 것들이다.

## 화면

- **글자가 배경에 묻힌다** — 동심원·도트·사진 위의 글자. 글자 쪽에 `scrim()` 을 깔거나, 무늬의 중심을
  화면 반대편으로 옮기고 바깥으로 갈수록 흐려지게 한다. 작은 라벨은 배경색 외곽선(`stroke`, 6~8px).
- **강조색 글자 + 강조색 배경** — 같은 색끼리 겹치면 사라진다. 배경이 강조색인 장면에선 글자를 잉크색으로.
- **비네트가 글자를 회색으로 만든다** — 가장자리 글자가 탁해 보이면 비네트 시작 반경을 키우거나 세기를 0.3대로.
- **블룸 과다** — 도트·글자가 번져 민트/흰색으로 뭉개지면 0.4 이하로.
- **텍스트가 잘린다** — 캔버스는 자동 줄바꿈이 없다. `measure()` 로 폭을 재고 `wrap()` 으로 나눈다.
  세로 배너·긴 날짜처럼 폭이 큰 글자는 끝이 화면 안에 들어오는지 마지막 프레임에서 확인.
- **반복 무늬가 들킨다** — 같은 사진을 쌓아 군중을 만들면 같은 얼굴이 보인다. 줄마다 반전·크기·밝기·블러를
  다르게, 뒷줄일수록 어둡고 흐리게. 그래도 많으면 사용자에게 소재 추가를 제안.
- **전환 순간 HUD가 안 보인다** — 바탕색이 바뀌는 와이프 동안 HUD 색을 미리 바꾼다.
- **오려 붙인 인물** — 밝기·채도·대비를 장면 톤에 맞추고 뒤 그림자. 인물 위로 떨어지는 빛이나 안개를 얹으면 더 붙는다.
- **이미지 비율이 늘어난다** — `<img>` 대신 캔버스 `drawImage` 로 그리고, 원본 비율을 지킨다.

## 내용

- **사실만** — 숫자·날짜·이름·약속은 사용자가 준 자료에 있는 것만. 없으면 비워 두거나 "예시"로 표시하고 물어본다.
  기관·회사 소개 영상에서 그럴듯한 통계를 지어내는 것이 가장 위험하다.
- **공식 로고** — 직접 그린 마크는 "공식 로고가 아님"을 사용자에게 분명히 알린다. 공식 로고는 원본 파일을 받는다.
- **채팅에 붙여 넣은 이미지는 파일로 안 올 수 있다** — 디스크에 없으면 "파일 첨부로 다시" 요청.
  아주 작은 로고(가로 200px 이하)를 받으면 8배 키우며 가장자리를 다시 세우는 처리(Lanczos 확대 → 흰색과의 혼합량으로
  알파 추정 → smoothstep으로 경계 세우기 → 색 언블렌드)를 하고, 원본 파일을 함께 요청한다.
- **사람 사진 편집** — 사용자가 준 인물 사진의 옷·배경을 바꿀 땐 얼굴·안경·머리·자세를 그대로 두라고
  생성 프롬프트에 명시하고, 결과를 보여 확인받는다.
- **음악 저작권** — 사용자가 준 상업 음원은 그대로 쓰되, 게시 시 제한될 수 있음을 한 줄 알리고 음원 파일은
  저장소에 커밋하지 않는다(.gitignore).

## 렌더·파일

- **폰트가 대체 글꼴로 나온다** — `document.fonts.load` 를 모든 굵기에 대해 기다린 뒤 `sceneReady`.
  스틸에서 한글이 고딕 기본체로 보이면 폰트 파일 이름·경로를 확인.
- **결정적이지 않다** — `Math.random`, `Date`, 누적 상태를 그림에 쓰면 워커마다 프레임이 달라 영상이 튄다.
  모든 것은 t의 함수로, 무작위는 `hash(i)`.
- **용량이 너무 크다** — 도트·그레인은 압축이 어렵다. 그레인 2프레임마다, CRF 22. 그래도 크면 2-pass 비트레이트.
- **ffmpeg가 반복문 입력을 먹는다** — 셸 `while read` 안에서 ffmpeg를 돌리면 `-nostdin`.
- **링크가 안 열린다** — 샌드박스 네트워크가 막은 것이면 호스트 이름을 알려 주고, 내용을 붙여 넣거나 파일로
  달라고 한다. 막힌 내용을 짐작으로 채우지 않는다.
