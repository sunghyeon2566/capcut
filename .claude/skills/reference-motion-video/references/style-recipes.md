# 스타일 레시피

레퍼런스가 아래 셋 중 하나와 닮았으면 해당 레시피와 `examples/` 의 완성본을 먼저 읽고 시작한다.
완성본은 실제로 렌더해 사용자가 만족한 영상의 전체 코드다. 폰트 경로만 이 프로젝트의
`fonts/<Family>-<weight>.ttf` 규칙으로 바꾸면 그대로 돌아간다.

닮은 레시피가 없으면, 레퍼런스에서 "반복되는 장치"(배경 처리, 글자 등장 방식, 전환, 장식 요소)를
3~6개 뽑아 템플릿의 도우미(halftone, rise, stripeWipe, circleWipe, stairWipe, glitch, hud …)로
하나씩 옮긴다. 새 장치가 필요하면 시간만 받는 함수로 만든다.

## 목차
1. 하프톤 HUD 런칭 필름 (검정 + 네온 단색)
2. 기업 인포그래픽 (남색 + 호박색, 챕터 HUD)
3. 세로 쇼츠 밈 (상단 제목 + 노란 자막 + 사진 합성)
4. 공통 수치(크기·타이밍) 기준

---

## 1. 하프톤 HUD 런칭 필름 — `examples/halftone-hud-launch.html`

알아보는 법: 검은 화면, 네온 한 색(초록·시안 등) 도트 무늬, 모서리 브래킷과 모노 라벨,
터미널 타자, 굵은 그로테스크 대문자 단어 한 개씩, 마지막에 흰 바탕 로고.

- **도트 질감**: 모든 그래픽을 `halftone(fn, color)` 로 찍는다. `fn(x,y)` 는 0..1 밝기.
  - 동심원: `0.5+0.5*cos(2π(r/λ - t*speed))` 를 `sstep(0.48, 0.8, ·)` 로 날카롭게(λ≈100px).
  - 간섭무늬: 두 중심의 cos 합. 터널: `log(r)` 간격의 링(`ph = log(r/40)*2.3 - t*1.7`).
  - 구: 램버트 음영 `n·L` + 경도 띠. 임의 모양(로고·마크): 1/4 크기 오프스크린에 흰색으로 그려
    `getImageData` 로 샘플링.
  - 셀 12px(1080p). 더 작으면 모아레·용량 폭증.
- **블룸**: 프레임을 1/4로 줄여 blur(3px) 후 `lighter` 로 0.4 정도. 0.6 이상이면 도트가 민트색으로 뭉갠다.
- **HUD**: 모서리 L자 브래킷(여백 48px, 팔 26px), 상단 가운데·하단 가운데 십자선, 왼쪽 위
  테두리 박스 라벨(`FILE № …`), 오른쪽 위 `CLASS: … / STATUS: …`, 아래 좌우 모노 라벨.
- **글자**: 큰 단어 + 그 아래 모노 한 줄(영문 대문자 · 한국어 설명). 등장은 아래에서 밀려 오르는 마스크
  리빌 + RGB 분리(빨·초·파를 `lighter` 로 몇 px 어긋나게 그렸다가 0으로).
- **컷**: 하드컷 + 컷 ±2프레임 가로 띠 글리치, 큰 전환에만 흰 섬광 1~2프레임.
- **배경과 글자가 겹칠 때**: 글자 쪽에 `scrim()` 어둠을 깔고, 도트 필드 중심을 반대편으로 옮긴다.
  같은 색 글자를 같은 색 도트 위에 두지 않는다(초록 위 초록 글자는 안 읽힌다).
- **마지막**: 흰 종이색 배경 + 마크 + 워드마크 + 모노 URL(스크램블 후 확정) + 작은 각주.

## 2. 기업 인포그래픽 — `examples/corporate-infographic.html` (+ `.sound.py`)

알아보는 법: 남색 바탕에 따뜻한 빛 번짐과 떠다니는 먼지, 위쪽 `— EYEBROW` + 큰 제목,
연혁 타임라인·아이콘 단계·숫자 카운터·막대그래프·도트 그리드, 사선 띠·원·계단 와이프,
오른쪽 위 `LABEL CH 03 / 07`, 아래 가운데 진행 점, 오른쪽 아래 `TC 00:00:05:18`.

- **챕터 구조**: 7개 안팎, 각 2~5초. 레퍼런스의 챕터 순서를 그대로 쓰고 내용만 바꾼다
  (연혁→문제 제기, 작동 방식→단계, 실적→숫자, 매출 추이→비교, 비전→가져갈 것, 로고→참여 안내).
- **타임라인**: 선이 왼쪽에서 그어지고 머리 점이 지나갈 때 마디가 켜진다(마디 시각 = 머리가 닿는 시각).
- **아이콘 단계**: 원(r≈100) + 바깥 얇은 링이 돌고, 안에 선 아이콘(흰색 + 강조색). 원 사이 점선 화살표의
  점 3개가 흐른다. 번호 `01` · 제목 · 한 줄 설명을 원 아래에.
- **숫자 화면**: 강조색 전면 + 은은한 사선 띠 이동, 큰 숫자는 Montserrat 800(약 200px) 카운트업,
  단위는 한국어 굵게, 아래 밑줄이 자란다. 숫자는 **사용자가 준 자료에 있는 것만**.
- **전환**: 사선 띠(주황 앞날 + 호박색 몸통)가 경계 순간 화면을 덮음, 마지막 아이콘에서 원이 커져
  다음 바탕색이 됨, 계단식 남색이 덮음. 전환 순간 HUD 색(밝은/어두운)을 미리 바꾼다.
- **사운드**: `sound_kit.Mix.beat_bed` 로 120BPM 비트, 전환마다 휙+임팩트, 등장마다 팝, 카운터에 틱,
  엔딩에 종소리 화음.

## 3. 세로 쇼츠 밈 — `examples/vertical-shorts-meme.html`

알아보는 법: 1080×1920, 위 1/4이 검은 띠(빨간 태그 + 흰 줄 + 노란 줄 제목),
아래는 영상, 영상 위에 노란 가사 자막(한국어 위·영어 아래)과 반투명 회색 설명 박스.

- **배치(1080×1920 기준)**: 검은 헤더 0–525, 태그 중심 y≈245(빨강 #b8141f, 글자 연노랑),
  제목 1줄 y≈368 흰색, 2줄 y≈466 노랑(#ffd400), 66px 900.
  가사 한국어 y≈1236(35px 900), 영어 y≈1296(45px Montserrat 800), 둘 다 노랑 + 검은 외곽선·그림자.
  설명 박스 top≈1340, 줄 간격 38px, rgba(0,0,0,.6), 46자/초로 타자처럼 채움.
- **사진 합성**: 인물은 `rembg`(`birefnet-portrait`)로 오려 WebP로 저장. 군중은 같은 단체 사진을
  여러 줄로 쌓는다(줄마다 좌우 반전·크기·밝기·블러를 달리하고, 아래쪽은 그라디언트로 지워 겹침 경계를 숨김).
  카메라 푸시는 레이어마다 depth 계수로 다르게 커지게(패럴랙스).
- **톤 맞추기**: 스튜디오에서 찍은 밝은 인물은 `brightness(.86) saturate(.78) contrast(1.12)` +
  뒤 그림자(blur 60)로 어두운 장면에 붙인다. 안 하면 오려 붙인 티가 난다.
- **음악이 주어진 경우**: `audio_profile.py` 로 템포·드롭을 찾고, 레퍼런스의 자막 전환 시각(4fps로
  자막 영역을 잘라 타일로 보면 정확히 보인다)을 그대로 쓴다. 렌더 때 `--audio` 로 먹인다.

## 4. 공통 수치 기준 (1920×1080)

| 항목 | 값 |
|---|---|
| 안전 여백 | 좌우 100px, HUD 모서리 40~48px |
| 큰 제목 | 72~96px (Black Han Sans 또는 Noto Sans KR 900) |
| 본문 한 줄 | 28~40px, 보조 설명은 24~28px 회색 |
| 머리말(eyebrow) | Montserrat 800 19px, 자간 6 |
| 등장 리빌 | 0.35~0.45초, eOutExpo, 항목 간격 0.2~0.4초 |
| 장면 길이 | 정보 1개당 최소 1.5초 읽을 시간. 글자 줄 수 × 0.6초 이상 머무르게 |
| 전환 | 0.4~0.8초, 경계 시각에 화면을 가장 많이 덮게 |
| 컷 격자 | 120BPM이면 0.5초. 음악이 있으면 그 곡의 박 |
| 그레인 | overlay 0.04, 2프레임마다 갱신 |
| 인코딩 | x264 CRF 22, yuv420p, faststart (웹 게시용은 2-pass 4Mbps로 15MB 이하) |
