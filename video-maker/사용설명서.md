# 📜 민담 영상 자동 제작기 사용설명서

이미지 + 나레이션 + 자막(SRT)을 넣으면 캡컷(CapCut) 초안을 자동으로 만들어 줍니다.
캡컷에서 초안을 열고 **내보내기** 버튼만 누르면 mp4 영상이 완성돼요.

## 자동으로 해 주는 것
- 이미지를 나레이션 길이에 맞게 나눠서 배치 (문장 중간에 장면이 바뀌지 않도록 자막 시작에 맞춤)
- 이미지마다 **줌인 / 줌아웃 / 왼쪽→오른쪽** 움직임을 랜덤으로 (같은 효과는 연속으로 안 나옴)
- 나레이션 넣기
- 자막을 **한 줄 15자 이내**로 나눠서, **흰 글씨 + 굵은 검정 외곽선**, 화면 아래에 넣기
- 화면 1920×1080, 30fps

## 처음 한 번만 준비하기

### 1단계. 파이썬 설치
1. https://www.python.org/downloads/ 에서 노란 **Download Python** 버튼 클릭 후 설치
2. 검은 창에 `Open Settings now ... [y/N]` 이 나오면 **y** 입력 후 Enter
   - 열린 설정 화면(앱 실행 별칭)에서 **Python (default)**, **Python install manager** 를 **켬**
   - **앱 설치 관리자 python.exe / python3.exe** 는 **끔**
   - 설정 창을 닫고 검은 창으로 돌아가기
3. 이후 검은 창에서 질문이 나오면 모두 **y** 입력 후 Enter (파이썬 설치까지 자동 진행)
4. 확인: 시작 메뉴에서 `cmd` 실행 → `python --version` 입력 → `Python 3.xx` 가 나오면 성공
   - 예전 설치 화면이 나오는 경우엔 맨 아래 **"Add python.exe to PATH"** 체크 후 **Install Now**

### 2단계. 캡컷(PC 버전) 설치
- https://www.capcut.com 에서 PC용 캡컷 설치 후 로그인

### 3단계. 이 프로그램 받기
- 이 `video-maker` 폴더를 내 컴퓨터에 복사 (예: `D:\민담제작기`)

### 4단계. 설치
- 폴더 안의 **`1_설치하기.bat`** 더블클릭 → "설치 끝!"이 나오면 완료

### 5단계. 캡컷 초안 폴더 주소 알아두기
- 캡컷 실행 → 오른쪽 위 **설정(톱니바퀴)** → **초안 위치** 에 나온 주소를 복사
- 보통 `C:\Users\내이름\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft`

## 영상 만들 때마다

1. **`2_실행하기.bat`** 더블클릭 → 브라우저에 제작 화면이 열려요
2. ① 이미지 140장, ② 나레이션, ③ 자막(.srt) 넣기
   - 이미지 파일 이름은 `1.png, 2.png … 140.png` 처럼 **숫자 순서**로 해 주세요
3. 처음 한 번은 **캡컷 초안 폴더 위치**에 5단계에서 복사한 주소 붙여넣기 (다음부터는 기억해요)
4. **🎬 영상 만들기** 클릭 → "완성!"이 나올 때까지 기다리기
5. 캡컷을 열면(이미 열려 있으면 껐다 켜기) 새 초안이 보여요
6. 초안 열기 → 확인 → 오른쪽 위 **내보내기** → 해상도 **1080p**, 프레임 **30fps** → 내보내기

## 대본으로 그림과 내용 정확히 맞추기 (선택)
대본 문장 앞에 **[이미지 번호]** 를 붙여서 ④ 칸에 붙여넣으면, 그 문장이 나레이션에 나올 때 그 이미지로 바뀌어요.

```
[1] 옛날 옛적, 조선 시대 어느 깊은 산골 마을에 떡장수 할머니가 살았습니다.
[2] 할머니는 매일 고개를 넘어 장에 떡을 팔러 다녔지요.
[3] 첫 번째 고개를 넘는데, 커다란 호랑이가 불쑥 나타났어요!
```
- `[1]`, `[이미지 1]`, `[장면 1]`, `[그림 1번]` 모두 돼요
- 첫 번호 앞의 글(제목 등)은 무시해요
- 나레이션/SRT를 다른 곳에서 만들어서 글자가 조금 달라도 비슷한 부분을 찾아서 맞춰요
- 번호를 안 붙인 이미지는 앞뒤 사이에서 자동으로 나눠요
- 메모장(.txt) 파일로 불러오기도 돼요
- 만든 뒤 `작업파일\초안이름\장면_확인표.txt` 에서 이미지마다 언제 나오는지 확인할 수 있어요
- 예시: `대본_예시.txt`

  (mp4로 내보낸 다음에는 지워도 됩니다)
- 자막을 15자로 나눈 결과는 `작업파일\초안이름\자막이름_15자.srt` 로도 저장돼요. (유튜브 자막으로 쓸 수 있어요)
- 자막 크기가 너무 크거나 작으면 화면의 **자막 글자 크기** 숫자를 바꿔서 다시 만들면 돼요.
- 같은 이름으로 다시 만들면 이전 초안을 덮어써요.

## 숫자 바꾸고 싶을 때 (maker.py 맨 위)
| 이름 | 뜻 | 기본값 |
|---|---|---|
| `MAX_CHARS` | 자막 한 줄 최대 글자 수 | 15 |
| `BORDER_WIDTH` | 검정 외곽선 두께 | 60 |
| `SUBTITLE_Y` | 자막 높이 (-1이 맨 아래) | -0.8 |
| `ZOOM_BIG` | 줌 확대 정도 (1.15 = 15%) | 1.15 |
| `PAN_MOVE` | 좌우 이동 거리 | 0.12 |
