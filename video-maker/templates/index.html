📜 민담 영상 자동 제작기

이미지 + 나레이션 + 자막을 넣으면 캡컷 초안을 자동으로 만들어 드려요.

파일 이름 순서(1, 2, 3 … 140)대로 들어가요. 폴더째 고르려면 아래 버튼을 쓰세요.

한 줄에 15자가 넘으면 자동으로 나눠서 한 줄씩 보여줘요.

"몇 번 이미지는 몇 번 자막부터" 적은 메모장 파일이에요. 한 줄에 이미지번호 자막번호 (예: 3 12).
일부만 적어도 되고, 안 넣으면 자동으로 나눠요. 예시는 장면표_예시.txt 를 보세요.

캡컷 → 설정 → 초안 위치에 나오는 주소를 붙여넣으세요. (한 번 넣으면 기억해요)
