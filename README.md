## 수강생 쇼핑몰 빌더

쇼핑몰 강의 수강생용 상품 소개 페이지(상품 15개)를 만들어 주는 기능입니다.

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 강사 관리자 | `/shop-admin` | 상호·쇼핑몰 주소·수강생 비밀번호를 넣어 쇼핑몰 생성, 상호 변경, 비밀번호 재설정, 삭제 |
| 수강생 쇼핑몰 | `/shop/<주소>` | 소비자가 보는 화면. 상품 이미지를 누르면 등록한 링크로 이동 |
| 수강생 관리자 | `/shop/<주소>/admin` | 상품 15개(이미지·이름·가격·정가·배지·링크) 등록, 색상·공지·로고·배너·하단 정보 꾸미기, 실시간 미리보기 |

- 강사 비밀번호: 환경변수 `SHOP_ADMIN_PASSWORD` (기본값 `admin1234` — 운영 전 반드시 변경)
- 세션 서명 키: 환경변수 `SESSION_SECRET`
- 데이터는 `data/shops.json`, 업로드 이미지는 `data/uploads/` 에 저장됩니다.
  파일에 저장하는 방식이므로 디스크가 유지되는 서버(VPS, Docker 볼륨 등)에서 `npm run build && npm start` 로 운영해야 하며,
  Vercel 같은 서버리스 환경에서는 데이터가 유지되지 않습니다.
