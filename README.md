## 온라인 강의실 (강의 녹화본 제공)

| 주소 | 내용 |
| --- | --- |
| `/class` | 수강생 강의실 홈 — 로그인 · 회원가입(아이디 · 비밀번호 · 이름 · 휴대폰 번호) · 개설 과목 목록 |
| `/class/과목주소` | 과목별 독립 페이지 — 왼쪽 카테고리 메뉴, 카테고리별 녹화본 목록, 보호된 영상 플레이어 |
| `/admin` | 관리자 페이지 — 수강생 관리, 과목(페이지) · 카테고리 · 영상 업로드, 보안 설정 |

### 운영 전 필수 설정 (`.env.example` 참고)

```
SESSION_SECRET=길고-임의의-문자열
ADMIN_USERNAME=admin
ADMIN_PASSWORD=관리자-비밀번호
```

설정하지 않으면 관리자 계정은 `admin / admin1234` 이며, 관리자 화면 상단에 경고가 표시됩니다.

### 데이터 저장 위치

- `data/academy.json` — 수강생 · 과목 · 카테고리 · 영상 목록 · 보안 설정
- `data/videos/` — 업로드한 영상 파일 (public 폴더가 아니므로 로그인한 수강생만 받을 수 있음)

두 경로 모두 개인정보 · 대용량 파일이라 git 에 올리지 않습니다(.gitignore). **서버 디스크에 파일로
저장하므로 Vercel 같은 서버리스 호스팅에서는 동작하지 않습니다.** 디스크가 유지되는 서버(VPS,
클라우드 VM 등)에서 `npm run build && npm start` 로 실행하고, 위 두 경로는 주기적으로 백업하세요.

### 녹화 · 유출 방지 기능

- 시청자 워터마크(이름 · 아이디 · 전화번호 뒷자리 · 시각, 위치 이동) — 유출자 추적
- 다른 창/탭 이동, 캡처 단축키(PrintScreen, ⌘+Shift, Win+Shift+S) 감지 시 영상 정지 · 가림
- 다운로드 버튼 · 우클릭 · 드래그 · PIP 차단, 영상 파일 직접 주소 접근 차단
- 한 계정 한 기기 로그인(계정 공유 방지)

웹에서는 휴대폰 촬영이나 녹화 프로그램을 완전히 막을 수 없습니다. 녹화 화면을 검게 만들려면
DRM(Widevine/FairPlay) 영상 호스팅(예: Kollus, VdoCipher) 연동이 필요합니다.
