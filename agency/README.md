# 우리가게 광고영상 (1인 광고영상 대행) — 랜딩 페이지

- `landing/index.html` : 랜딩 페이지 한 장 (그대로 올리면 바로 열려요). 맨 아래 `CONFIG` 만 바꾸면 돼요.
  - `brand` 대행사 이름 · `chat` 1:1 오픈채팅방 링크 · `endpoint` 신청서를 받을 구글 시트(Apps Script) 주소 · `business` 사업자 정보
  - `partners` : 파트너마다 주소 끝에 `?p=아이디` 를 붙여 나눠 주면, 그 파트너 이름과 오픈채팅이 보이고 신청서에 파트너가 함께 적혀요.
- `landing/v/` : 페이지에 들어간 실제 제작 영상(광고영상제작기 레퍼런스 카드)과 표지.
- `endpoint` 가 비어 있으면 '샘플 화면' 띠가 보이고 신청 내용은 저장되지 않아요.
