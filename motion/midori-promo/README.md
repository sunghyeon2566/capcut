# 緣 미도리 홍보 모션 (55초 · 16:9 1920×1080 + 9:16 1080×1920 · 30fps)

서주골·봉고뒷고기와 같은 레퍼런스(앱 런칭 필름)의 문법으로 만들었습니다. 초록 조명은 레퍼런스 원래 색 그대로입니다(미도리 = 초록).

- **리뷰 중심:** 리뷰 키워드 스캔, 리뷰 카드, 리뷰 타자, 리뷰 키워드 배지
- **마무리:** 골목 간판 사진 → 약도(핀·2번 출구에서 67m) → 엔딩

`index.html`(16:9)과 `vertical.html`(9:16)이 같은 `film.js`를 씁니다. 장면 시간이 같아 나레이션 대본 하나로 두 버전에 맞습니다.

## 다시 만들기

```bash
python3 sound.py
```

```bash
node render.mjs . --audio out/sound.wav --out out/midori-promo-16x9.mp4
```

```bash
node render.mjs . --page vertical.html --audio out/sound.wav --out out/midori-promo-9x16.mp4
```

## 사실 확인

- **리뷰 문장:** 받은 리뷰 5건에서 그대로 썼습니다.
  - '40년째 운영', '1986년부터 운영 푯말', '칸막이 방', '토요일 영업'도 리뷰에서 가져왔습니다.
  - 된장국수처럼 아쉬운 평은 이번 리뷰에는 없었습니다.
- **메뉴 10가지:** 받은 메뉴판 사진 그대로입니다. 도시락정식의 '우동 포함'은 메뉴판의 うどん付입니다.
- **약도:** 받은 지도를 보고 다시 그린 것입니다(명동역 · 2번 출구 · 퇴계로 · 남산예장공원). 지도 이미지 파일을 받으면 실제 지도로 바꿀 수 있습니다.
- **'회덮밥' 장면의 사진:** 채소 위 회·초장·김가루 사진이 회덮밥인지 회무침인지는 확인이 필요합니다. 화면 속 제목은 '신선한 야채와 회'로 두었습니다.
- **로고:** 공식 로고 파일이 없어 간판의 '緣 미도리'를 글자로 넣었습니다.
