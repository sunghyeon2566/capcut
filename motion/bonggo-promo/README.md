# 봉고뒷고기 홍보 모션 (50초, 1920×1080, 30fps)

서주골 영상과 같은 레퍼런스(앱 런칭 필름)의 문법으로 만들었고, **리뷰 맛집**을 중심에 두었습니다.

- 리뷰 키워드 스캔 (쫄깃 · 꼬숩 · 부드럽고 · 신선해서)
- 리뷰 카드와 리뷰 타자 장면
- '고기 질이 좋아요' 키워드 배지
- 마무리: 간판 사진 → 지도(핀·주소) → 엔딩

사진·간판·지도는 받은 실사 이미지(`assets/`)입니다.

## 구성

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–3 | 휴대폰 등장 (숯불 사진) | 리뷰가 먼저 **알아본 집.** |
| 3–5.5 | 숯불 사진 + 리뷰 키워드 고리 | REVIEW SCAN · 리뷰가 말하는 **그 맛.** |
| 5.5–8.5 | 3 카운터 + 메뉴 카드 (상차림 사진) | 고기는 딱 **세 가지.** |
| 8.5–11 | 기울어진 화면 + 리뷰 카드 | 뒷고기는 쫀득, **특목살은 부드럽게.** |
| 11–14 | 쌈 사진 + 키워드 배지 | 고기 질이 **좋아요.** |
| 14–19.5 | 메뉴 목록 → 기본 상차림 + 반찬 카드 | 고기 다 먹고, **마무리는 된장국수.** → 미나리도 **함께.** |
| 19.5–27.5 | (보라) 리뷰 타자 + 리뷰 카드 2장 | 리뷰가 **증명하는 맛집.** |
| 27.5–33 | 화면 다섯 개 | 쫄깃. 꼬숩. **신선.** → 리뷰 맛집 **봉고뒷고기.** |
| 33–37.5 | (밤) 간판 사진 | FIND US · 불 켜진 간판, **봉고 뒷고기.** |
| 37.5–44.5 | (밤) 지도 + 핀 + 주소 | 대구 동구 **단산길 7-15** · 단산저수지 바로 앞 · 이시아폴리스 건너편 · ☎ 053-984-1235 |
| 44.5–50 | 엔딩 | 리뷰 맛집 · 봉고뒷고기 · 리뷰가 증명하는 **숯불 뒷고기** |

## 나레이션

`narration.txt`에 장면 시간에 맞춘 대본이 있습니다. 배경음은 나레이션을 얹을 수 있게 낮게 깔았습니다.

## 다시 만들기

```bash
python3 sound.py
```

```bash
node render.mjs . --audio out/sound.wav --out out/bonggo-promo.mp4
```

## 사실 확인

- **리뷰 문장:** 받은 리뷰 캡처의 문장을 그대로 썼습니다. 된장국수에 대한 아쉬운 평 한 줄은 뺐습니다.
- **'세 가지 고기', '기본 반찬', '소갈비살 인기':** 리뷰 요약에서 가져왔습니다.
- **주소·전화:** 받은 매장 정보(대구 동구 단산길 7-15, 053-984-1235)입니다.
- **위치 설명:** '단산저수지 바로 앞 · 이시아폴리스 건너편'은 받은 지도를 보고 쓴 것입니다.
- **로고:** 공식 로고 파일이 없어 이름은 글자로 넣었습니다.
