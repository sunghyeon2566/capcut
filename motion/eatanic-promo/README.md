# 조선 팰리스 이타닉 가든 홍보 모션 (55초 · 16:9 1920×1080 + 9:16 1080×1920 · 30fps)

서주골·봉고뒷고기·미도리·삼청동수제비·STAY와 같은 레퍼런스(앱 런칭 필름)의 문법으로 만들었습니다. 조명은 '정원'과 초록 대리석 카운터의 짙은 초록에 샴페인 금빛입니다.

- **미슐랭 맛집 강조:**
  - 오프닝 "미슐랭 맛집, 이타닉 가든."
  - 금색 '미슐랭 맛집' 도장이 쾅 찍히는 장면(옆에 '미쉐린 가이드 서울 2026')
  - 화면 다섯 개 장면 "미쉐린 가이드 서울 2026 이타닉 가든."
  - 지도 핀 이름표
  - 엔딩 도장 + '미쉐린 가이드 서울 2026'
- **리뷰 중심:** 리뷰 키워드 스캔, 리뷰 카드, 리뷰 타자, 리뷰에 나온 계절 요리 배지
- **마무리:** 주방 사진 + 미쉐린 가이드 소개 문장 → 약도(핀 · 8번 출구에서 411m) + 주소 → 엔딩

`index.html`(16:9)과 `vertical.html`(9:16)이 같은 `film.js`를 씁니다. 장면 시간이 같아 나레이션 대본 하나로 두 버전에 맞습니다.

## 구성

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–3 | 휴대폰 등장 (고기 요리 사진) | 미슐랭 맛집, **이타닉 가든.** |
| 3–5.5 | 요리 사진 + 리뷰 키워드 고리 | REVIEW SCAN · 리뷰가 말하는 **그 한 접시.** |
| 5.5–8.5 | '미슐랭 맛집' 도장 + 인증 정보 카드 (미쉐린 가이드 서울 2026 · 흑백요리사2 방영) | 새로운 '식(食)'으로의 **초대.** |
| 8.5–11 | 기울어진 화면 (생선 사진) + 리뷰 카드 | 생선 요리도, **싹싹 긁어서.** |
| 11–14 | 코스 사진 + 계절 요리 배지 넷 | 계절마다, **새로운 코스.** |
| 14–19.5 | 리뷰 속 요리 여섯 → 한 접시 + 주방 사진 + 리뷰 | 정해진 메뉴 없이, **제철로.** |
| 19.5–28 | (보라) 리뷰 타자 + 리뷰 카드 2장 | 계절마다 **또 가고 싶은 곳.** |
| 28–32 | (밤 파랑) 코스와 와인 + 주방 사진 | 반박자 빠른 **서비스.** |
| 32–37.5 | 화면 다섯 개 | 예쁘게. 맛있게. **세심하게.** → 미쉐린 가이드 서울 2026 **이타닉 가든.** |
| 37.5–42 | 주방 사진 (초록 대리석 카운터 · 아치) | 도심 속 정원을 떠올리게 하는 **36층의 공간.** |
| 42–49 | 약도 + 주소 | 서울 강남구 **테헤란로 231** · 조선 팰리스 36층 · 역삼역 8번 출구에서 411m · ☎ 02-727-7610 |
| 49–55 | 엔딩 | 미슐랭 맛집 도장 · 이타닉 가든 · 새로운 '식(食)'으로의 **초대.** |

## 사실 확인

- **미슐랭:**
  - 받은 '인증 정보'의 '미쉐린 가이드 서울 2026'을 근거로 '미슐랭 맛집'을 넣었습니다.
  - 별 개수나 등급은 받은 자료에 없어 쓰지 않았습니다.
  - 도장은 직접 그린 글자 도장이며 미쉐린 로고나 별 모양이 아닙니다.
- **쓰지 않은 말:** 리뷰의 '월드 베스트 레스토랑'은 받은 자료로 확인되지 않아 넣지 않았습니다.
- **소개 문장:**
  - '새로운 식(食)으로의 초대', '한국의 식문화에 대한 깊이 있는 연구'는 받은 가게 소개에서 가져왔습니다.
  - '도심 속 정원', '정해진 메뉴는 없으며', '제철 재료'는 받은 미쉐린 가이드 소개에서 가져왔습니다.
- **리뷰 문장:** 받은 리뷰 6건에서 그대로 썼습니다.
- **요리 이름:**
  - 메뉴판이 없어 리뷰에 나온 요리 이름만 썼습니다: 송이죽 · 잡채 · 수계탕 · 토마토냉채 · 돼지올스타 · 만둣국.
  - 사진 속 요리 이름은 알 수 없어 '생선 요리', '코스 한 접시', '오늘의 한 접시'처럼 보이는 대로 적었습니다.
- **가게 사진:**
  - 외관 사진은 대화 중에 보내 주셔서 파일로 받지 못했습니다. 그래서 마무리 장면에는 주방 사진을 넣었습니다.
  - 외관 사진 파일을 받으면 바꿀 수 있습니다.
- **사진 크기:** 받은 사진이 작아(가로 165~560픽셀) 2.5~4배로 키우고 살짝 선명하게 했습니다.
- **약도:**
  - 받은 지도를 보고 다시 그렸습니다(역삼역 · 선릉역 · 2호선 · 8번 출구 · 신라스테이 역삼 · GS타워 등).
  - '테헤란로' 길 이름은 주소에 맞춰 넣었습니다.
- **영업시간:** 받은 정보에는 '12:00에 영업 시작'만 있어 넣지 않았습니다.
