# 서주골 홍보 모션 (49.5초, 1920×1080, 30fps)

레퍼런스(앱 런칭 필름)의 문법으로 춘천 서주골(항아리 장작구이)을 소개합니다. 레퍼런스에서 가져온 장치는 다음과 같습니다.

- 어두운 조명 배경과 휴대폰 화면
- 화면에서 튀어나오는 카드
- 블러에서 맺히는 굵은 제목(끝 단어 강조색)과 작은 모노 머리말
- 빛줄기·하얀 섬광 전환, 화면 다섯 개 몽타주, 로고 엔딩

음식과 화덕은 매장 실사 사진(`assets/`)을 썼고, 사진마다 맛과 느낌을 설명하는 문구·카드를 붙였습니다. 룸 복도(사진 없음)와 항아리 마크는 직접 그린 그림입니다.

| 사진 | 쓰인 곳 | 붙인 설명 |
|---|---|---|
| `jar.jpg` 항아리 화덕 + 장작 | 첫 화면, 장작불 장면, 360° 장면 | 가게 앞에 쌓인 장작, 항아리 고리에 하나씩 |
| `ribs.jpg` 항아리 갈비 | 기울어진 화면, 메뉴, 로고 배경 | 윤기 흐르는 양념 · 불향 밴 겉면 · 촉촉한 속살 |
| `pork.jpg` 불 위 화로 한 판 | 갈비도, 삼겹살도 | 결대로 썬 고기를 불 위 화로에 올려 끝까지 따뜻하게 / 식탁 위에서도 꺼지지 않는 불 |
| `stew.jpg` 김치찌개 | 찌개 장면 | 두부를 듬뿍 넣어 보글보글 끓인 김치찌개 |
| `sides.jpg` (갈비 사진 위쪽) | 반찬 카드 | 곁들이는 반찬 |

## 구성

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–3 | 휴대폰 등장 (항아리 화덕 사진) | 항아리에 걸어 **굽습니다.** |
| 3–5.5 | 화덕 사진으로 밀고 들어감, 굽는 중 % 고리 | WOOD FIRE · 장작불 향이 **배어듭니다.** |
| 5.5–8.5 | 360° 카운터 + 굽는 방식 카드 | 사방에서, **골고루.** |
| 8.5–11 | 기울어진 화면 (갈비 사진) + 느낌 카드 | 겉은 윤기, **속은 촉촉.** |
| 11–13.5 | 갈비 → 불 위 화로 사진 + 불꽃 카드 | 갈비도, **삼겹살도.** |
| 13.5–19 | 메뉴 목록 → 김치찌개 사진 + 반찬·한 상 카드 | 찌개 한 그릇까지 **든든하게.** → 보글보글, **한 상 가득.** |
| 19–24 | (청록) 룸 + 물결 | GATHERING · 여럿이 함께, **편하게.** |
| 24–28 | 예약 화면 + '대기 없이 바로 입장' | RESERVATION · 예약하고 **바로 입장.** |
| 28–36 | (보라) 리뷰 타자 + 리뷰 카드 | REVIEWS · 다녀간 분들의 **진짜 후기.** |
| 36–41.5 | 화면 다섯 개 | 장작. 항아리. **한 상.** → 춘천 **서주골.** |
| 41.5–49.5 | 로고 (뒤로 흐릿한 갈비 사진) · 특별 서비스 · 안내 | 예약을 하시고 오시는 분들께는 **특별한 서비스** 또한 제공해 드리겠습니다 |

## 다시 만들기

```bash
python3 sound.py
```

```bash
node render.mjs . --audio out/sound.wav --out out/seojugol-promo.mp4
```

- 문구는 `index.html`의 `COPY`와 각 장면 함수(`sHook` … `sLogo`)에 있습니다.
- 시간은 `T`, 색은 `C`에서 고칩니다.

## 확인할 것

- **로고:** 항아리 마크는 직접 그린 것이고 공식 로고가 아닙니다. 공식 로고 파일이 있으면 교체합니다.
- **메뉴 이름:** '항아리 갈비'는 사진을 보고 붙인 이름입니다. '항아리 삼겹살'은 리뷰에 나온 이름입니다.
- **리뷰 문장:** 받은 리뷰 2건에서 그대로 인용했습니다. 리뷰어 이름은 넣지 않았습니다.
- **'대기 없이 바로 입장':** 두 리뷰의 방문 정보('예약 후 이용', '대기 시간 바로 입장')를 근거로 했습니다.
- **찌개 사진:** 받은 파일이 171×216으로 작아서 4배 키우고 선명하게 다듬었습니다. 원본 크기 사진이 있으면 바꿔 넣는 것이 좋습니다.
- **글꼴:** Pretendard와 JetBrains Mono를 썼습니다. 둘 다 SIL OFL입니다.
