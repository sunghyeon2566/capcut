# 삼청동수제비 — 시네마 광고 (30초 · 16:9 1920×1080 · 30fps)

받은 레퍼런스 광고(고기집 시네마 광고, 30초, 125BPM)의 문법으로 만들었습니다. 사진은 받은 세 장(항아리 수제비 · 숟가락 수제비 · 쭈꾸미)을 여러 컷으로 나눠 썼습니다. 나레이션은 없습니다.

## 레퍼런스에서 가져온 것

- **화면:** 위아래 검은 띠(처음엔 거의 닫혀 있다가 열림), 어둡고 따뜻한 색, 얕은 초점(가운데만 선명), 천천히 밀고 당기는 카메라
- **리듬:** 125BPM, 4박(1.92초)마다 하드컷. 컷 시각은 레퍼런스와 같은 박
- **자막:** 왼쪽 아래 두 줄. 첫 줄은 보통 굵기, 둘째 줄은 굵게 들여쓰기. 흐림에서 맺히며 등장
- **로고:** 오프닝의 큰 로고 → 왼쪽 위 작은 로고 → 엔딩의 큰 로고 + 한 줄 + 흰 위치 상자
- **쇼케이스:** 음악이 터지는 15.36초에 짧은 섬광, 나무 이름표(쭈꾸미 · 수제비)
- **뺀 것:** 오른쪽 위 가맹 문의 전화번호 (요청대로)

## 구성

| 시간 | 컷 | 자막 |
|---|---|---|
| 0–3.84 | 항아리 수제비 전체 + 김 | 큰 로고 '삼청동수제비' · 미슐랭 맛집 |
| 3.84–9.6 | 수제비 접사 → 숟가락 → 고추양념·김치 | 재료 하나하나에 / **정성을 들여 빚습니다** |
| 9.6–15.36 | 김가루 그릇 → 항아리 → 숟가락 | 깊게 우려낸 멸치 육수와 / **얇게 떠 낸 수제비** |
| 15.36–18.24 | (섬광) 쭈꾸미 · 수제비 + 나무 이름표 | 줄 서서 먹는 / **미슐랭 맛집** (금색) |
| 18.24–23.04 | 쭈꾸미 접사 두 컷 → 숟가락 | 매콤하게 볶아낸 쭈꾸미, / **수제비와 함께라 더 좋습니다** |
| 23.04–26.4 | 숟가락 접사 → 항아리 | 어머니가 만들어주신 / **그 맛 그대로 준비합니다** |
| 26.4–30 | 항아리 접사 + 김 | 큰 로고 · 미슐랭 맛집 · 한 번 맛보면, 줄 서는 이유를 압니다 · 위치 상자 |

## 다시 만들기

```bash
python3 sound.py
```

```bash
node render.mjs . --audio out/sound.wav --out out/samcheong-cine-16x9.mp4
```

- 문구는 `index.html`의 `COPY`에서 고칩니다.
- 컷과 사진 위치는 `SHOTS`에서 고칩니다.
- 색 보정은 `GRADE`에서 고칩니다.

## 사실 확인과 창작

- **창작 문구:** 자막은 요청대로 새로 썼습니다. 내용은 앞서 받은 자료에 맞췄습니다.
  - 멸치 육수 · 얇은 수제비 · 쭈꾸미와 수제비의 조화 · 줄 서는 집: 방문 리뷰
  - 정성 · 어머니가 만들어주신 맛: 가게 소개글
- **미슐랭 맛집:** 사용자가 알려 준 대로 썼습니다. 별 개수나 연도는 쓰지 않았습니다.
- **로고:** '삼청동수제비' 붓글씨와 김 나는 그릇 마크는 직접 만든 것이며 가게의 공식 로고가 아닙니다.
- **음악:** 레퍼런스 음악은 쓰지 않았습니다. 같은 박자(125BPM)로 새로 합성한 가이드 트랙(`sound.py`)이고, 끓는 소리와 지글지글 소리를 넣었습니다.
- **글꼴:** Pretendard, 나눔손글씨 붓(Nanum Brush Script), 고운바탕(Gowun Batang)을 썼습니다. 모두 OFL 라이선스입니다.
