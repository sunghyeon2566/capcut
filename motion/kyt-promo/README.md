# 새로운 책쓰기 연구소 · 홍보 모션그래픽

9:16 세로형(1080 × 1920, 30fps, 32.5초) 홍보 영상입니다.
릴스·쇼츠·틱톡에 바로 올리거나 CapCut 에서 이어서 편집할 수 있습니다.

| 파일 | 용도 |
| --- | --- |
| `out/kyt-promo.mp4` | 완성본 (자체 합성 배경음 + 효과음 포함) |
| `out/kyt-promo_no-audio.mp4` | 무음 버전 — CapCut 에서 음악을 직접 넣을 때 |
| `index.html` | 영상 원본. 브라우저로 열면 바로 재생·탐색됩니다 |
| `render.cjs` | `index.html` 을 프레임 단위로 캡처해 MP4 로 만드는 스크립트 |
| `audio/make_audio.py` | 배경음·효과음 합성 (외부 음원 없음, 저작권 걱정 없음) |
| `assets/kyt-logo-original.webp` | 받은 로고 원본 |
| `assets/kyt-emblem.webp` | 엔드카드용 로고 (액자 테두리와 하단 워터마크를 잘라내고 가장자리를 배경에 녹임) |

## 구성 (레퍼런스 영상의 흐름을 그대로 따름)

| 시간 | 장면 | 화면 |
| --- | --- | --- |
| 0.0 – 4.4 | 훅 질문 | **내 이름**으로 된 책, 언젠가 쓰고 싶으셨죠? — 빈 표지의 책 |
| 4.4 – 10.0 | 고민 3컷 | 막막한 **첫 문장.** (원고지) → 끝나지 않는 **퇴고.** (빨간 줄 원고) → 흩어진 **메모와 기억들.** (메모 조각) |
| 10.0 – 13.8 | 브랜드 전환 | `새로운 책쓰기 연구소` 타이핑 — 메모 조각이 날아와 한 권의 책으로 |
| 13.8 – 21.3 | 3단계 | STEP 01 기획(차례) · STEP 02 집필(원고지 + 탈고 진행률) · STEP 03 퇴고(문장 다듬기) |
| 21.3 – 25.0 | 장르 선택 | 에세이 / 자기계발 / 전문서 토글 — 표지가 회전목마처럼 전환 |
| 25.0 – 27.5 | 마무리 | 기획부터 출간까지, **함께** 씁니다. — 펼친 책에서 로고의 새싹이 자라남 |
| 27.5 – 32.5 | 엔드카드 | KYT 로고(빛 스윕·반짝임) · 연구소명 · 슬로건 · 상담 전화 버튼 |

배경음은 96BPM 이고 장면 경계가 모두 박자(0.625초)에 맞춰져 있어
CapCut 에서 다른 음악으로 바꿀 때도 같은 템포의 곡을 고르면 컷이 잘 맞습니다.

## 문구 바꾸기

`index.html` 의 `COPY` 객체만 고치면 됩니다.
`*단어*` 는 골드 강조, `|` 는 줄바꿈입니다.

```js
const COPY = {
  hook:  '*내 이름*으로 된 책,|언젠가 쓰고 싶으셨죠?',
  phone: '010-8073-5149',
  ...
};
```

한 줄은 한글 9~10자 안쪽이 가장 보기 좋습니다.
화면 속 원고·차례·책 표지 문구는 예시이며, 엔드카드 하단에 그렇게 표기해 두었습니다.

## 미리보기

`index.html` 을 크롬으로 열면 자동 재생됩니다. 스페이스바로 일시정지,
하단 바로 원하는 시점을 탐색할 수 있습니다. (폰트는 Google Fonts 에서 불러오므로 인터넷 연결이 필요합니다.)

## 다시 렌더링하기

```bash
cd motion/kyt-promo
npm install --no-save playwright && npx playwright install chromium   # 처음 한 번
node render.cjs                          # out/kyt-promo.mp4 + 무음 버전
node render.cjs --stills 2,12,30         # 특정 시점 스틸 PNG 만 (out/stills/)
node render.cjs --from 10 --to 14        # 일부 구간만 빠르게 확인
node render.cjs --no-audio               # 배경음 없이
```

ffmpeg, python3 + numpy 가 필요합니다.
