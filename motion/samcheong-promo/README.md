# 삼청동수제비 홍보 모션 (55초 · 16:9 1920×1080 + 9:16 1080×1920 · 30fps)

서주골·봉고뒷고기·미도리와 같은 레퍼런스(앱 런칭 필름)의 문법으로 만들었습니다. 조명은 멸치 육수와 감자전 빛깔의 금빛 갈색입니다.

- **미슐랭 맛집 강조:**
  - 오프닝 제목
  - '미슐랭 맛집' 도장이 쾅 찍히는 장면
  - 리뷰 장면 끝맺음 "줄 서서 먹는 미슐랭 맛집."
  - 화면 다섯 개 장면
  - 지도 핀 이름표
  - 엔딩 도장
- **리뷰 중심:** 리뷰 키워드 스캔, 리뷰 카드, 리뷰 타자, 리뷰에 적힌 재료 배지
- **마무리:** 가게 한 상 사진 + 가게 소개글 → 약도(핀) + 주소 → 엔딩

`index.html`(16:9)과 `vertical.html`(9:16)이 같은 `film.js`를 씁니다. 장면 시간이 같아 나레이션 대본 하나로 두 버전에 맞습니다.

## 구성

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–3 | 휴대폰 등장 (항아리 수제비 사진) | 미슐랭 맛집, **삼청동수제비.** |
| 3–5.5 | 수제비 사진 + 리뷰 키워드 고리 | REVIEW SCAN · 리뷰가 말하는 **그 국물.** |
| 5.5–8.5 | '미슐랭 맛집' 도장 + 리뷰 속 메뉴 카드 | 줄 서는 데는, **이유가 있다.** |
| 8.5–11 | 기울어진 화면 (숟가락 사진) + 리뷰 카드 | 멸치 육수, **깊고 진하게.** |
| 11–14 | 항아리 사진 + 재료 배지 다섯 | 양도, **항아리 가득.** |
| 14–19.5 | 리뷰 속 메뉴 다섯 → 감자전 + 김치 사진 + 리뷰 | 수제비부터 **감자전까지.** |
| 19.5–28 | (보라) 리뷰 타자 + 리뷰 카드 2장 | 줄 서서 먹는 **미슐랭 맛집.** |
| 28–32 | (고추빛) 쭈꾸미 사진 + 물결 | 쭈꾸미는, **별미.** |
| 32–37.5 | 화면 다섯 개 | 깊게. 바삭하게. **푸짐하게.** → 미슐랭 맛집 **삼청동수제비.** |
| 37.5–42 | 가게 한 상 사진 + 소개글 | 엄선된 재료, 편안한 분위기, **푸짐한 인심.** |
| 42–49 | 약도 + 주소 | 서울 종로구 **삼청로 101-1** · 안국역 1번 출구 · ☎ 02-735-2965 |
| 49–55 | 엔딩 | 미슐랭 맛집 도장 · 삼청동수제비 · 어머니가 만들어주신 **맛 그대로.** |

## 다시 만들기

```bash
python3 sound.py
```

```bash
node render.mjs . --audio out/sound.wav --out out/samcheong-promo-16x9.mp4
```

```bash
node render.mjs . --page vertical.html --audio out/sound.wav --out out/samcheong-promo-9x16.mp4
```

## 사실 확인

- **미슐랭:**
  - 받은 리뷰 사진의 '미슐랭 맛집' 문구를 그대로 썼습니다.
  - 선정 연도나 등급(빕 구르망 등), 별 모양은 받은 자료에 없어 넣지 않았습니다.
  - 도장은 직접 그린 글자 도장이며 미슐랭 로고가 아닙니다.
- **리뷰 문장:**
  - 받은 리뷰 5건에서 그대로 썼습니다.
  - '감자전 별로였단 리뷰가 있었는데'처럼 아쉬운 평은 넣지 않았습니다.
  - '전용 주차장 · 발렛'은 리뷰 한 건에서 가져왔습니다.
- **메뉴:**
  - 메뉴판을 받지 못해 리뷰에 나온 이름만 썼습니다: 수제비 · 감자전 · 녹두전 · 파전 · 쭈꾸미.
  - 가격은 넣지 않았습니다.
- **반찬 이름:** 배추김치 · 열무김치 · 고추양념은 리뷰("테이블마다 놓여 있어서")에서 가져왔습니다.
- **가게 소개 문구:** '엄선된 재료, 편안한 분위기, 푸짐한 인심', '어머니가 만들어주신 맛'은 받은 가게 안내 글에서 가져왔습니다.
- **약도:**
  - 받은 지도를 보고 다시 그렸습니다(삼청로 · 삼청로7길 · 북촌로11길 · 북촌로15길 · 둘레 장소).
  - 지도 이미지 파일을 받으면 실제 지도로 바꿀 수 있습니다.
- **가게 사진:**
  - 가게 외관 사진 파일이 없어, 마무리의 '가게' 장면에는 가게 테이블에서 찍은 한 상 사진(숟가락 사진)을 넣었습니다.
  - 외관 사진을 받으면 `assets/spoon.jpg` 대신 넣어 바꿀 수 있습니다.
- **쓰지 않은 사진:** 밝은 카페 실내 사진(22번)은 픽업 카운터·빵 진열대가 보여 삼청동수제비 내부가 아닌 것 같아 넣지 않았습니다.
- **영업시간:** 받은 정보의 '20:00에 영업 종료'는 요일마다 다를 수 있어 넣지 않았습니다.
