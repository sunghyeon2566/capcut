# 딥마크온 클래스 무료 특강 모션

레퍼런스 인포그래픽 모션(남색 배경 + 호박색 빛, HUD 챕터·타임코드, 7챕터 구성)에 딥마크온 클래스 무료 특강 랜딩페이지 내용을 넣은 30초 영상입니다.

- 결과물: `out/deepmarkon-special.mp4` (1920×1080, 30fps, 30초, 사운드 포함)
- 소스: `index.html` 한 파일. 모든 프레임은 시간 `t`만으로 그려집니다.

## 구성

| 시간 | 챕터 | 내용 |
|---|---|---|
| 0–3 | 01 OPENING | 마크(호박색 원 + 재생 삼각형)와 빛살, "딥마크온 클래스 · 시니어 유튜브 수익화 무료 특강" |
| 3–8 | 02 CHECK | "열심히 만드는데, 왜 내 영상은 안 될까요?" 타임라인 CHECK 1·2·3 → "문제는 노력이 아니라 방법입니다." |
| 8–13 | 03 HOW IT WORKS | 누구나 1시간 안에 1시간짜리 영상: 대본 → 이미지 → 목소리·자막 → 자동 편집 |
| 13–17 | 04 TRACK RECORD | 노란 화면 카운터: 200명(챌린지 1·2기) · 60명(상장·상금) · 1시간 |
| 17–21 | 05 BEFORE / AFTER | 혼자 할 때 ✕ vs 특강 방법 ✓ |
| 21–25.5 | 06 TAKEAWAYS | 이번 특강에서 가져가실 것 4가지 + 도트 그리드 |
| 25.5–30 | 07 JOIN | 10월 30일 (금) 저녁 8시 30분 · 줌 온라인 → 로고 엔딩 |

전환: 사선 띠(01→02, 06→07), 원 확장(03→04), 계단(04→05). 컷은 120BPM(0.5초) 격자에 맞췄고 `sound.py`가 같은 격자로 비트와 효과음을 만듭니다.

## 렌더

```bash
python3 sound.py
```

```bash
node render.mjs --audio out/sound.wav
```

스틸만: `node render.mjs --stills 1.6,7.6,15.4,29.5`

## 고치는 곳

- 문구·날짜·수치: `COPY`
- 색: `C` (기본 호박색 `#F7B928`)
- 챕터 길이: `T` (바꾸면 `sound.py`의 `T`도 같이)

폰트: Black Han Sans(`fonts/`), Noto Sans KR·JetBrains Mono(`../seoul-city-hall/fonts`), Montserrat(`../sunghyeon-promo/fonts`) — 모두 SIL OFL.
