# 시그니엘 서울 STAY 홍보 모션 (55초 · 16:9 1920×1080 + 9:16 1080×1920 · 30fps)

서주골·봉고뒷고기·미도리·삼청동수제비와 같은 레퍼런스(앱 런칭 필름)의 문법으로 만들었습니다. 조명은 STAY 실내의 노란 의자와 금빛 조명 색입니다.

- **셰프 강조:** '미쉐린 3스타 셰프 야닉 알레노' 배지가 쾅 찍히는 장면, 엔딩 배지
- **리뷰 중심:** 리뷰 키워드 스캔, 리뷰 카드, 리뷰 타자, 리뷰에 적힌 맛 배지
- **마무리:** STAY 실내 사진 + 가게 소개글 → 약도(핀) + 주소 · 출구 · 전화 · 영업시간 → 엔딩

`index.html`(16:9)과 `vertical.html`(9:16)이 같은 `film.js`를 씁니다. 장면 시간이 같아 나레이션 대본 하나로 두 버전에 맞습니다.

| 8.5–11 | 기울어진 화면 (페이스트리 접시) + 리뷰 카드 | 한 코스, **한 코스.** |

## 사실 확인

- **미쉐린 3스타:**
  - 가게 소개글의 "미쉐린 3스타 셰프 '야닉 알레노'" 그대로, 셰프에 대한 말로만 썼습니다.
  - STAY 자체가 3스타라는 뜻으로 읽히지 않게 했습니다.
  - 리뷰 한 건에 '원스타'라는 말이 있지만, STAY의 등급은 받은 자료로 확인되지 않아 화면 문구로 쓰지 않았습니다.
  - 배지는 직접 그린 글자 배지이며 미쉐린 로고나 별 모양이 아닙니다.
- **리뷰 문장:**
  - 받은 리뷰 5건에서 그대로 썼습니다.
  - "가격에 뷰 값이 포함되었다는 생각"처럼 기대가 낮았다는 부분은 넣지 않았습니다.
- **메뉴:**
  - 메뉴판을 받지 못했습니다.
  - 리뷰의 '런치&디너'와 편의시설 안내(와인 페어링 · 소믈리에 · 글루텐프리 메뉴 · 비건 메뉴 · 콜키지 유료)만 썼고, 가격은 넣지 않았습니다.
- **요리 이름:**
  - '캐비아 카놀리', '새우와 벌집꿀', '코스 한 접시'는 사진에 보이는 대로 붙인 이름입니다. 실제 메뉴 이름이 있으면 바꿀 수 있습니다.
  - 리뷰의 '랍스터 요리' 문장은 어느 사진인지 알 수 없어 사진과 짝짓지 않았습니다.
- **주소 · 교통 · 전화 · 영업시간:** 받은 정보 그대로입니다.
  - 서울 송파구 올림픽로 300 롯데월드타워 81층
  - 잠실역(2·8호선) 2번 출구에서 27m
  - 02-3213-1230
  - 매일 06:30–21:30, 브레이크타임 10–12시 · 14:30–18시, 라스트오더 20:00
  - 주차 가능, 발렛 35,000원
- **약도:**
  - 받은 지도를 보고 다시 그렸습니다(잠실역 2·8호선, 석촌호수, 롯데마트, 롯데백화점, 롯데월드 등).
  - '올림픽로' 길 이름은 주소에 맞춰 넣었습니다.
- **사진:**
  - 받은 사진이 작아서(가로 170~720픽셀) 2.5~4배로 키우고 살짝 선명하게 했습니다. 원본 사진을 받으면 더 또렷해집니다.
  - 시그니엘 입구 사진은 위에 겹쳐 있던 자막과 재생 버튼을 피해 두 부분(문 · SIGNIEL 글자)으로 잘라 썼습니다.
