# 숲속우산 참송이버섯 상품 소개 모션 (52초 · 16:9 1920×1080 + 9:16 1080×1920 · 30fps)

레퍼런스(종이 공예 · 120BPM)의 문법: 크림 종이 위 타자 → 종이 찢김 → 초록 종이 언덕 → 번호 카드 넷 → 동그라미 셋 → 언덕 장면 → 마무리.
포인트: **노부부가 직접 키우고 직접 판매까지**, **웃으며 키운 건강한 버섯**.

`index.html`(16:9)과 `vertical.html`(9:16)이 같은 `film.js`를 씁니다. 장면 시간이 같아 나레이션 대본(`narration.txt`) 하나로 두 버전에 맞습니다.

## 구성

| 시간 | 장면 | 문구 |
|---|---|---|
| 0–4 | 크림 종이 · 참송이 · 느타리 소품 | 포천 숲속에서 키우고, 농장에서 바로 보냅니다. |
| 4–10 | 종이 찢김 → 언덕 · 버섯이 자란다 | 노부부가 **웃으며 키운** 건강한 버섯. |
| 10–14 | 01 카드 + 참송이 사진 · 통나무 | 참송이버섯 · 향과 식감이 뛰어난 포천 버섯 |
| 14–18 | 02 카드 + 느타리 사진 둘 | 느타리버섯 · 포천에서 정성껏 길렀어요 |
| 18–22 | 03 카드 + 무농약 배지 | 친환경 무농약 · 인증 제10304983호 |
| 22–26 | 04 카드 + 100% 도장 · 물방울 | 100% 국내산 · 포천의 맑은 물과 깨끗한 공기 · 베타글루칸 풍부 |
| 26–32 | 동그라미 셋 | 키우고, 따서, 보내기까지. 재배부터 판매까지, **노부부가 모두 직접.** |
| 32–37.5 | 농부 사진 + 종이 노부부 · 하트 | 웃으며 키운 버섯, 건강하게 자랐어요. |
| 37.5–41.5 | 요리 사진 + 고객 후기 | 찢어서 마늘소스에 무쳐 먹으면 간단하고 맛있더라고요. |
| 41.5–46.5 | 약도 + 주소 · 주차 · 버스 | 경기 포천시 창수면 옥수로 49 |
| 46.5–52 | 우산 버섯 로고 | 숲속우산 참송이버섯 · 010-6395-2676 |

## 다시 만들기

```bash
python3 sound.py
node render.mjs . --audio out/sound.wav --out out/숲속우산참송이버섯_상품소개_16x9.mp4
node render.mjs . --page vertical.html --audio out/sound.wav --out out/숲속우산참송이버섯_상품소개_9x16.mp4
```

스틸 확인: `node render.mjs . --stills 2,7.5,12` (세로는 `--page vertical.html` 추가)

## 고치는 곳

- 문구 · 전화 · 주소: `film.js` 의 `COPY`, 카드 문구는 `CARDS`
- 장면 시각: `film.js` 의 `T` (소리는 `sound.py` 의 `T` 도 같이)
- 색: `film.js` 의 `C`

## 알아둘 점

- 사진은 받은 이미지 5장(`assets/`). 할머니 사진은 없어서 노부부는 종이 그림으로 그렸습니다.
- 지도는 받은 지도를 보고 다시 그린 약도입니다.
- 무농약 인증은 공식 마크를 그리지 않고 인증번호를 글자로만 넣었습니다.
- 효능 문구(면역력 강화 등)는 넣지 않았습니다. 운영 시간은 넣지 않았습니다.
